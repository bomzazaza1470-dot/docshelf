# DocShelf · ชั้นเอกสาร

เว็บไซต์เก็บและจัดการไฟล์ PDF ในหน้าเดียว เป็นไฟล์ HTML ไฟล์เดียว (`index.html`) ไม่ต้องมีเซิร์ฟเวอร์

**ความเป็นส่วนตัว:** ไฟล์ PDF ที่อัปโหลดเก็บไว้ในเบราว์เซอร์ของผู้ใช้แต่ละคน (IndexedDB) ไม่ถูกส่งไปที่เซิร์ฟเวอร์ และคนอื่นมองไม่เห็น

## ฟีเจอร์

- อัปโหลด PDF หลายไฟล์พร้อมกัน (คลิก ลากมาวาง หรือแตะบนมือถือ)
- เปิดอ่านในหน้าเว็บ ดาวน์โหลด และลบไฟล์ (กดยืนยันซ้ำก่อนลบ)
- จัดหมวดหมู่: สร้าง ลบ และย้ายไฟล์ระหว่างหมวด
- รายการโปรด (★) และเปลี่ยนชื่อไฟล์
- เลือกหลายไฟล์เพื่อย้ายหมวดหรือลบทีเดียว
- ค้นหาตามชื่อ เรียงลำดับ (ใหม่สุด เก่าสุด ชื่อ ขนาด)
- ภาพตัวอย่างหน้าแรกและจำนวนหน้า
- สลับมุมมองการ์ด/รายการ และโหมดสว่าง/มืด
- สำรองและกู้คืนข้อมูลเป็นไฟล์ `.json`
- ดูพื้นที่ที่ใช้ และล้างข้อมูลทั้งหมดในเครื่อง

## วิธีใช้

1. เปิด `index.html` ในเบราว์เซอร์ (หรือเปิดผ่านลิงก์ที่โฮสต์ไว้)
2. คลิกหรือลากไฟล์ PDF ไปที่กล่องอัปโหลด
3. กด "เปิดอ่าน" เพื่ออ่าน กดชิปด้านบนเพื่อกรองตามหมวด

## ข้อควรรู้

- ไฟล์อยู่ในเบราว์เซอร์และเครื่องนั้นเท่านั้น ย้ายข้ามเครื่องด้วยปุ่ม **สำรองข้อมูล** แล้ว **กู้คืน**
- ถ้าล้างข้อมูลเบราว์เซอร์ ไฟล์จะหาย ควรสำรองเป็นระยะ
- โหมดส่วนตัว (Private/Incognito) อาจไม่เก็บไฟล์ถาวร
- ภาพตัวอย่างต้องใช้อินเทอร์เน็ตตอนสร้างครั้งแรก (โหลดตัวอ่าน PDF จาก cdnjs) ฟอนต์โหลดจาก Google Fonts

## การนำขึ้นเว็บด้วย GitHub Pages

1. สร้างที่เก็บไฟล์ใหม่บน GitHub ตั้งเป็น **Public**
2. อัปโหลด `index.html` (ชื่อไฟล์ต้องเป็น `index.html`)
3. ไปที่ **Settings → Pages** ตั้ง Source เป็น **Deploy from a branch** เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอ 1–3 นาที จะได้ลิงก์รูปแบบ `https://ชื่อผู้ใช้.github.io/ชื่อที่เก็บไฟล์/`
